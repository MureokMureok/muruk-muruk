# MVP 스펙 v1 (작성 중)

## 결정 사항
- [ ] 방향: 연합 기획전
- [ ] 쿠폰 사양: (정률 1종 - 할인율 / 최대 할인액 / 최소 주문 / 유효기간 / 사용처 / 양도 불가)
- [ ] 재원 구조: (모의 한도만 구현, 환급·출금 제외)
- [ ] 쏠림 대응: (가게별 발급 상한, 예산 소진 시 해당 가게 쿠폰만 발급 중단)
- [ ] 계정: (소셜 로그인 1종, 가맹점·KCP는 시드 계정)
- [ ] 시연 시나리오: (8장면)

## MVP 필수 / 확장 / 후속
- MVP: 한도 등록, 쿠폰 발행, 나머지 가게 쿠폰 발급, 사용 검증·소각, 재사용 거절
- 확장: 선물·교환, 정산 화면, 체인 기록 조회
- 후속: 실제 PG 결제·취소, 원화 정산
