# 무럭무럭 (Muruk-Muruk)

중소 온라인 가맹점이 함께 여는 **연합 기획전** 플랫폼.
한 가맹점에서 구매하면 참여한 다른 가맹점의 쿠폰이 자동 발급되고, 쿠폰의 소유·조건·사용 상태는 스마트컨트랙트(ERC-1155)로 검증합니다.

> NHN KCP 산학협력 프로젝트 (디지털자산 마이크로디그리). 구현 범위는 `docs/mvp-spec.md` 기준입니다.

## 폴더 구조

| 폴더 | 내용 | 담당 |
|---|---|---|
| `frontend/` | React 웹앱 (소비자 / 가맹점 / KCP 관리자 화면) | |
| `backend/` | Spring Boot + JPA + MySQL API, 컨트랙트 호출 | |
| `contracts/` | 스마트컨트랙트 (ERC-1155 쿠폰, 한도·검증·소각) | |
| `docs/` | MVP 스펙, 화면 정의서, API 명세, 회의록 | |

## 브랜치 규칙

- `main`: 시연 가능한 상태만. **직접 푸시 금지**, PR로만 반영
- `develop`: 영역 통합용. 영역별 브랜치를 PR로 합칩니다
- `feature/contracts`, `feature/backend`, `feature/frontend`: 영역별 작업 브랜치
- 한 영역을 두 명 이상이 하면 `feature/frontend-로그인`처럼 한 단계 더 따서 작업

작업 순서: `git pull` → 자기 브랜치로 이동 → 작은 단위로 커밋·푸시 → 합칠 때 PR 생성 → 한 명이 훑어보고 머지

## 커밋 메시지

`type: 내용` 형식 (예: `feat: 쿠폰 발급 API 추가`)

`feat` 기능 / `fix` 버그 / `docs` 문서 / `refactor` 구조 변경 / `test` 테스트 / `chore` 설정·기타

## 비밀값 규칙 (중요)

- `.env`, 개인키, 키 파일은 **절대 커밋하지 않습니다.** (`.gitignore`에 포함됨)
- 필요한 변수 이름은 각 폴더의 `.env.example`에만 적고, 실제 값은 배포 환경 변수(Vercel, AWS)나 안전한 경로로 공유합니다.
- 실수로 커밋했다면 푸시 전이라면 즉시 알리고, 푸시했다면 해당 키를 폐기·재발급합니다.
