# frontend

React 웹앱. 소비자(모바일 폭) / 가맹점 / KCP 관리자 화면.

- 배포: Vercel (루트 디렉터리를 `frontend/`로 지정)
- 시연용 목업 HTML이 기준 화면입니다. 목업의 화면·문구를 이식합니다.

React + Vite (JavaScript). Node.js 20.19 이상 필요.

## 실행 방법

```bash
cd frontend
npm install      # 처음 한 번 (패키지 설치)
npm run dev      # 개발 서버 → http://localhost:5173
```

- `npm run build`: 배포용 파일을 `dist/`에 만듦
- `npm run lint`: 코드 검사 (oxlint)
- 백엔드 주소는 `.env.example`을 복사해 `.env`로 만들고 `VITE_API_BASE_URL`을 채움

## 로그인 (현재: 모의 로그인)

백엔드 로그인 API 연결 전까지 `src/auth/mockAuth.js`의 가짜 로그인을 씁니다.

| 방법 | 결과 |
|---|---|
| PAYCO·카카오·Google 버튼 | 소비자로 로그인 → `/home` |
| 아이디 `user` / `1234` | 소비자 → `/home` |
| 아이디 `store` / `1234` | 가맹점 과수원집 → `/store` |
| 아이디 `store2`·`store3` / `1234` | 가맹점 봄꽃상회·바다찬 |
| 아이디 `kcp` / `1234` | KCP 관리자 → `/admin` |

- 소비자 화면은 소비자 와이어프레임 v0(Figma) 기준입니다. 홈·기획전·상품은 **로그인 없이** 볼 수 있고, 결제·쿠폰함·MY에서 로그인합니다. 로그인 후 원래 화면으로 돌아옵니다(구매가 자동으로 진행되지는 않음).
- 로그인 안 한 상태로 `/store`, `/admin`에 들어가도 로그인 화면으로 보내고, 로그인 후 원래 화면으로 돌아옵니다.
- 다른 역할의 화면 주소로 들어가면 자기 역할의 첫 화면으로 보냅니다.

## 가짜 백엔드 (모의 API)

백엔드 API가 나오기 전까지 `src/api/api.js`가 서버 역할을 합니다.

- 화면은 `api.js`의 함수만 부릅니다. 진짜 백엔드가 나오면 함수 안쪽을 `fetch` 호출로 바꾸면 됩니다. (함수 옆 주석에 제안한 API 주소)
- 데이터는 브라우저 localStorage(`muruk.db`)에 저장됩니다. 역할을 바꿔 로그인해도 같은 데이터를 써서 장면이 이어집니다.
- 처음 상태는 `src/api/seed.js`. **MY 화면 또는 콘솔 왼쪽 아래 "시연 데이터 처음으로"**로 되돌릴 수 있습니다.
- 블록 번호·체인 기록은 모의 값입니다.
- 예시 데이터를 바꾸면 `seed.js`의 `SEED_VERSION`을 올리세요. 브라우저에 저장된 예전 데이터가 자동으로 새 데이터로 바뀝니다.

## 다크 모드

MY → 설정 → **다크 모드 · 시스템 설정에 맞추기** (기본: 끔). 켜면 휴대폰·PC가 다크 모드일 때 소비자 화면이 어둡게 보입니다. 가맹점·KCP 콘솔은 그대로입니다. 색 값은 `styles/app.css` 맨 아래.

## 시연 8장면 순서

| # | 로그인 | 화면 | 할 일 |
|---|---|---|---|
| 1 | `kcp` | 입금·한도 | 과수원집 입금 → **한도 등록** |
| 2 | `store` | 쿠폰 발행 | "첫 구매 감사" 쿠폰 **발행** |
| 3 | `store` → `kcp` | 연합 기획전 → 기획전 승인 | 마지막 가게로 **서명** → 규칙 잠금 → KCP **승인** |
| 4 | 카카오 등 | 홈 → 과수원집 상품 → 결제 | 다른 가게 쿠폰 2장 + 첫 구매 보너스 1장 **발급** |
| 5 | 소비자 | 쿠폰함 | 받은 쿠폰 확인 (사용 가능 / 사용 완료 / 만료) |
| 6 | 소비자 | 봄꽃상회 쿠폰 → 사용하기 → 결제 | 다른 가게에서 **사용** (25,000원 → 22,000원) |
| 7 | 소비자 | 사용 결과 → "같은 쿠폰 다시 써보기 (시연용)" | **재사용 거절** → 발급·사용 기록 보기 |
| 8 | `store2` → `kcp` | 정산 → 체인 기록 | 할인 부담·돌려받을 충전금, 전체 기록 **조회** |

- 한도 등록 전에는 쿠폰 발행·기획전 서명이 막힙니다. 기획전 승인 전에 구매하면 기획전 쿠폰은 발급되지 않습니다.
- 선물·교환(MVP 확장)은 아직 없습니다.
